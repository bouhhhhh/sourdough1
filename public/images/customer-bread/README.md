# Customer Bread Photos

Add your customer bread photos to this directory.

## File Naming
Name your files as:
- bread-1.jpg
- bread-2.jpg
- bread-3.jpg
- etc.

## Recommended Specifications
- **Format**: JPG or PNG
- **Size**: 800x800px (square)
- **File size**: Under 500KB for optimal performance
- **Orientation**: Square format works best

## Tips
- Use high-quality photos that showcase the bread clearly  
- Square cropping ensures consistent display
- Optimize images before adding them (use tools like TinyPNG or Squoosh)
- You currently have 8 photo slots configured (bread-1.jpg through bread-8.jpg)

## Adding More Photos
To add more photos beyond 8, edit `/src/components/customer-bread-gallery.tsx` and add more entries to the `customerPhotos` array.
